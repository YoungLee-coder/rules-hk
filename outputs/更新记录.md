## 未核实 / 共享依赖 / 限制

- **未逐条复验** OpenAI Help Center 列表中的 Intercom、SendGrid、Stripe、Sentry 等第三方运营域名；默认不代理，避免误伤非 AI 流量。
- **Cursor 登录**：10 月 30 日前网络仍可能回退 `authenticator.cursor.sh`（已由 `cursor.sh` 覆盖）；之后必须可达 `accounts.spacex.ai` / `accounts.x.ai`。
- **`DOMAIN-SUFFIX,spacex.ai`** 按官方建议采用后缀以覆盖未来 auth 子域；若企业仅允许最小主机列表，可改为精确 `DOMAIN,accounts.spacex.ai,PROXY`（需自行维护新增 auth 主机）。
- **普通 X 社交**（`x.com` / `twitter.com`）仍直连；仅 Grok / xAI / 上述 Grok 附属域走代理。
- 单次 DNS 或 HTTP 探测失败不作为删除域名的依据。
